# Keyo PCB

This directory contains the PCB design files and fabrication documentation for **Keyo**.

## Design Information
- **EDA Tool**: EasyEDA Pro (v3.2)
- **Layer Count**: 2 Layers
- **Dimensions**: Custom footprint for 9 mechanical switches, ESP32-S3 microcontroller, and 0.91" I2C OLED display

## Included Files
- `BOM.xlsx`: Detailed Bill of Materials with manufacturer and LCSC part numbers.
- `PickAndPlace.xlsx`: Component centroid coordinates for SMT automated assembly.

## Manufacturing Files
The ready-to-order Gerbers and drill files are located in [`production/gerbers.zip`](../production/gerbers.zip).
